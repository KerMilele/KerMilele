# Enhancement Three — Databases

For this enhancement, I migrated the product and order data from hardcoded React files and Firebase Firestore to a MySQL relational database.

I created three related tables: `products`, `orders`, and `order_items`. I connected MySQL to the Express backend to retrieve products, save customer orders, update inventory, and display order history.

I also improved database security by using parameterized SQL queries, environment variables for credentials, and a database user with limited permissions.

This enhancement demonstrates my skills in relational database design, SQL, backend development, and data management.
